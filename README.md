# Dialogys Explorer

Offline search engine for Renault & Dacia Dialogys documentation.

## Features

- Fast SQLite search
- Search by document title
- Search by keywords
- NT (Technical Notes)
- MR (Repair Manuals)
- Direct PDF opening
- Offline operation

## Technology

- Python 3
- SQLite
- SumatraPDF
